02Why

One guard. Every way out.

beforeunload alone misses in-app navigation, and router blockers only work with that router. leaveguard covers both from outside your framework.

  • Reload and tab close

    The browser's own leave dialog, only while dirty.

  • Links, before your router

    Asks on same-origin clicks, then lets the router run.

  • Back and forward

    Stops history traversal via the Navigation API.

  • Any framework

    One function. React hook included.

  • One prompt, not two

    Say yes once and the page leaves without a second ask.

  • Tiny

    0.7 kB gzipped, typed, zero dependencies.

03Use

Tell it when you're dirty.

Pass a function that says whether there are unsaved changes. It returns a function that removes the guard.

import { leaveguard } from 'leaveguard';

const stop = leaveguard(() => form.dirty, {
  message: 'Discard your changes?',
});

Your message shows for in-app navigation. On reload, browsers show their own text.

04Frameworks

Same guard, everywhere.

Start it when the form mounts. Stop it when the form goes away.

Leave nothing unsaved.
